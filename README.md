# Diego Alves — SQL Test Answers

A professional Streamlit presentation of the Global Fidelis SQL / Business Analytics assessment.

## What the app includes
- Recruiter-facing overview
- Data model and relationship explanation
- Questions 1a–3b
- T-SQL solution for every question
- Business logic and assumptions
- Key SQL concepts
- Clearly separated optional synthetic practice data

## Run locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The assessment did not provide a physical database. Synthetic data is included only for learning and validation and is never presented as company data.
